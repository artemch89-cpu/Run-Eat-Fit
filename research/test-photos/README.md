# Фото для сравнения моделей

Сюда — 20-30 реальных фото еды. Чем «хуже», тем полезнее:
плохой свет, снято под углом, недоеденная тарелка, несколько блюд разом.

Обязательно включить местную кухню (плескавица, айвар, чевапи, гречка,
сырники) — на ней модели ошибаются чаще, чем на бургерах и салатах.

Формат: jpg или png, имена любые.

Дальше: сравнительный прогон Haiku 4.5 против Sonnet 5, ответы рядом,
решение по модели для распознавания. Ориентир по цене: около 30 центов
на весь тест.
