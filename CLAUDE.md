# CLAUDE.md — Run Eat Fit

Читай этот файл первым при возврате к проекту. Полная спека — в `MVP-SPEC.md`, сырые материалы для методичек — в `research/`.

## Что это

Telegram-бот — персональный AI-тренер с памятью о жизни пользователя. Не калькулятор калорий (ниша занята — Calorie AI, FoodScan, FitnessAI Bot), дифференциация — живой коуч, который держит контекст жизни человека (стресс, перелёт, самочувствие) и подстраивает план под это.

## Статус

MVP-спека готова (07.09.2026), разработка ещё не начата.

## Ключевые решения (не пересматривать без веской причины)

- Аудитория: русскоязычные релоканты в Сербии, Telegram-only на старте, сербский язык — фича на потом
- Гипотеза успеха MVP: ежедневное возвращение пользователя к разговору, не оплата (цена — вторичная гипотеза, 300-1000₽/мес)
- Core loop: петля привычки — триггер (бот пишет первым) → минимальное действие → награда → план на срыв
- Тренировочные планы: гибрид — 2 профиля нагрузки на старте (выносливость, силовая), skill-методички курирует Артём вручную (веб-поиск по авторитетным источникам, НЕ GitHub), человек в цикле проверки обязателен
- Бот — conditioning/lifestyle-коуч (питание, разминка, восстановление), не тренер по технике конкретного спорта — под это не нужна экспертиза в каждом виде
- Фото еды — в MVP (Haiku 4.5, стандартное разрешение, не high-res)
- Модели: Sonnet 5 для диалога, Haiku 4.5 для фото
- Память: простая БД на юзера, НЕ векторная база, НЕ отдельный сервер на человека
- Оплата в MVP — вручную, переводом, первым 20-30 знакомым

## Явно ВНЕ MVP — не предлагать без явного запроса Артёма

Viber/кроссплатформенность, геймификация с блокировкой приложений (нужно нативное приложение), подключение часов/Strava, автоматическая мультивалютная оплата, полностью автономная генерация плана моделью без ограничения категорий и без методичек

## Оценка сроков

3-4 недели по 1.5 часа в день (~20-25 сессий), при условии не отвлекаться на пункты выше
